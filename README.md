# One-Step Is Enough to Judge: Hybrid Noise Skimming for Full-band Text-to-Audio Generation

**Project page:** https://briskmuntjack.github.io/muntjack-20262027/

Anonymous project page for a paper under double-blind review.
It contains the abstract, an overview of the proposed framework, audio samples
from the proposed method and baseline systems, and the main result tables.

## Contents

- `index.html` — the project page
- `audio/NN/*.wav` — 20 AudioCaps test captions × 6 systems (10 s clips, 16-bit PCM)
- `figures/framework.png` — framework overview
